Explore the impact of the requested change on this repository.

1. Read `wiki/tasks/scratchpad.md` when resuming active local work; otherwise start
   from `wiki/index.md`.
2. Inspect only relevant code and project documents.
3. Record findings under `wiki/exploratory/`.
4. Include affected modules and interfaces, dependencies, hardware/timing/power implications where applicable, risks, unknowns, validation impact, and recommended implementation tasks.
5. Link the exploration from the relevant task or exploratory index when useful.
6. Do not treat exploratory findings as accepted decisions.
7. Do not modify production code unless explicitly requested.
