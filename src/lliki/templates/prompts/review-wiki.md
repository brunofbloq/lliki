title: Semantic wiki health review
expected_total_tokens: 3000-10000
---
Review the project wiki for consistency and stale information.

1. Start with `wiki/index.md` and `wiki/wiki-rules.md`.
2. Check the active task and authoritative documentation links.
3. Identify contradictory facts, stale task statuses, duplication, exploratory findings treated as authoritative, unsupported decisions or lessons, and project-specific information incorrectly stored in the root agent contract.
4. Do not rewrite the whole wiki.
5. Apply only focused, evidence-supported corrections.
6. Report items requiring human validation separately.
